# Smart5 Nutrition React Website

## Run locally
```bash
npm install
npm run dev
```

## Logo
The uploaded Smart5 logo is already placed at:
`src/assets/images/logo.png`

## Add your own local images
Put your downloaded images inside:
`src/assets/images/`

Suggested filenames:
- hero-product.jpg
- mixed-dry-nut-powder.jpg
- almonds.jpg
- cashews.jpg
- pistachios.jpg
- walnuts.jpg
- about.jpg

## Vercel
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
